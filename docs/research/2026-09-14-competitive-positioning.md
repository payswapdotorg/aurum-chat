# Competitive Positioning — September 2026

Aurum should not position itself as a better generic enterprise chatbot. The current competitive field already contains strong products for enterprise search, workplace assistants and agent construction.

## Microsoft 365 Copilot / Copilot Studio

Microsoft positions Copilot around secure work data, Work IQ, enterprise applications and agent creation. Copilot Studio supports autonomous agents, publishing across channels, connected data and governance.

Aurum differentiation: company-goal-driven learning missions, cross-channel organizational identity, employee knowledge acquisition, explicit unknown management, neutral capability acquisition and BYOA across vendors.

Reference: https://www.microsoft.com/en-us/microsoft-365-copilot/microsoft-copilot-studio

## Slack AI / Agentforce

Slack positions enterprise search as a single place to search Slack and connected applications, and Agentforce agents can operate in Slack using connected enterprise context.

Aurum differentiation: Slack is one communication surface for Aurum rather than Aurum itself; the canonical company intelligence model spans channels, systems, external environment and organizational capability.

Reference: https://slack.com/features/enterprise-search

## Glean

Glean positions itself around enterprise context, connectors, knowledge graph, search, memory and agents. Its 2026 independent-agent positioning emphasizes agents with identities, access, memory, proactive behavior and human escalation.

Aurum differentiation: make the learning objective itself first-class—management goals drive what Aurum needs to know, who it should ask, which investigation to run and which new capability should be acquired.

References: https://www.glean.com/platform and https://www.glean.com/blog/introducing-independent-agents

## Atlassian Rovo

Rovo provides configurable AI teammates/agents that can use connected organizational knowledge and tools from Chat, Jira, Confluence and automation experiences.

Aurum differentiation: Rovo is centered around work in the Atlassian ecosystem; Aurum is horizontally focused on company intelligence and can recruit specialist agents/extensions for any industry.

Reference: https://support.atlassian.com/rovo/docs/agents/

## Strategic conclusion

Aurum wins when a company wants an **organizational intelligence employee**, not merely an AI assistant or a collection of task agents.

The moat to build is therefore not chat quality alone. It is the compounding company model:

`goals → observations → unknowns → learning missions → knowledge acquisition → evidence → organizational understanding → capability gaps/opportunities → authorized capability acquisition → outcomes → learning`
